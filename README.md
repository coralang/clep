## Contribution Guidelines

To submit a proposal, copy `templates/clep-template.md` to `proposals/new-your-title.md`, complete its metadata and text, and open a pull request. Leave `clep: null`; the workflow assigns the next identifier. Published proposal files may be named `clep-0001.md` or `clep-0001-title-slug.md`. Set `requires` to a list of CLEP numbers, or `[]` if the proposal has no dependencies.
